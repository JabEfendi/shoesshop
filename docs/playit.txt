## 🚀 CARA MENJALANKAN SHOESHOP 3D CONFIGURATOR (UNTUK PRESENTASI)

Buka **2 Tab Terminal** (satu untuk Laravel, satu untuk Vite):

### 📌 PERTAMA, SETUP PATH (jalankan di KEDUA terminal):
```bash
cd ~/Kerja/shoesshop
export PATH="$PWD/scripts/tools/nodejs/bin:$PATH"
```

---

### 🔵 TERMINAL 1 — START LARAVEL (Main Website + 3D Router):
```bash
php -S 127.0.0.1:8001 server.php
```
> Pakai `server.php` custom router di root proyek [server.php](file:///home/crashingtoy/Kerja/shoesshop/server.php) untuk support HTTP 206 Partial Content download GLB 65MB (supaya 3D tidak cacat / hanya sepotong tali).

---

### 🟢 TERMINAL 2 — START VITE (React HMR + CSS/JS Hot Reload):
```bash
npm run dev
```
> Menjalankan Vite build dev server, port auto **5173** (jika 5173 dipakai → 5174). Laravel Vite Plugin auto sinkron.
